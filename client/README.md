# EcoGrid AI Client Documentation

## Overview

EcoGrid AI is a web application designed to promote renewable and sustainable energy solutions using artificial intelligence. This project aims to provide real-time data visualization, AI predictions, and sustainability analytics to empower users in making informed decisions about energy consumption and generation.

## Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Backend**: FastAPI

## Features

- **Home Page**: Engaging hero section with animated illustrations, features, and benefits of using EcoGrid AI.
- **Dashboard**: Real-time weather and renewable energy data visualization, including KPIs and charts.
- **AI Prediction**: 24-hour renewable energy predictions with animated charts.
- **Reports**: Sustainability analytics and report export functionality.
- **Team Page**: Information about the team members involved in the project.
- **Chatbot**: A floating chatbot for user assistance across all pages.

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node Package Manager)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/your-repo/ecogrid-ai.git
   cd ecogrid-ai/client
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

### Folder Structure

- **src**: Contains all the source code for the application.
  - **app**: Main application files including routing and theme provider.
  - **components**: Reusable components for various functionalities.
  - **hooks**: Custom hooks for managing state and side effects.
  - **lib**: API calls and utility functions.
  - **pages**: Individual page components.
  - **styles**: Global styles and Tailwind CSS configurations.
  - **types**: TypeScript types and interfaces.

### Environment Variables

Make sure to set up your environment variables as needed. Refer to the `.env.example` file for guidance.
